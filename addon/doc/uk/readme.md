# Оповіщувач заряджання (Charging Notifier)

Доповнення для NVDA, яке дозволяє налаштовувати сповіщення про стан заряджання за допомогою голосових, звукових або обох типів оповіщень.

## Можливості

* **Звукові сповіщення**: відтворює окремі звукові ефекти, коли ваш пристрій підключається до мережі змінного струму або відключається від неї.
* **Гнучкість налаштування**: вибирайте між голосовими оголошеннями, звуковими сповіщеннями або обома варіантами відповідно до ваших уподобань.

## Налаштування

Додаток додає категорію **«Оповіщувач заряджання»** до діалогового вікна налаштувань NVDA (`NVDA+N` → Параметри → Налаштування).

### Тип сповіщення про стан заряджання

* **Голос**: використовує стандартні голосові оголошення NVDA про зміну стану живлення.
* **Звук** (за замовчуванням): відтворює звукові сигнали замість голосових оголошень.
* **Голос і звук**: забезпечує як звукові сигнали, так і голосові оголошення.
